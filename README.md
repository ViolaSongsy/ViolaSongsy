# Hi, I'm Viola

I build AI agents and web apps, with a focus on clear product flows, reliable business logic, and tests that catch real failures.

## Selected projects

### [Ciderlane Return Agent](https://github.com/ViolaSongsy/ciderlane-agent)
A conversational return assistant for a fictional retailer.

- **Focus:** keeping order verification, policy decisions, and external actions under application control.
- **Engineering:** explicit customer approval, durable idempotency keys, and multi-turn regression evaluations.
- **Stack:** Python · OpenAI Agents SDK · FastAPI · SQLite

[Explore the implementation](https://github.com/ViolaSongsy/ciderlane-agent#engineering-highlights) · [Design decisions](https://github.com/ViolaSongsy/ciderlane-agent/blob/main/docs/engineering-notes.md)

### [Shiguang · 拾光](https://github.com/ViolaSongsy/shiguang)
A self-hosted Chinese journal for small thoughts, moods, and optional AI reflections.

- **Focus:** a calm capture-and-review experience that keeps original entries separate from AI output.
- **Engineering:** account-scoped data access, rate-limit isolation, exports, and automated integration checks.
- **Stack:** TypeScript · Next.js · React · SQLite / Turso

[See the interface](https://github.com/ViolaSongsy/shiguang#screenshots) · [Run it locally](https://github.com/ViolaSongsy/shiguang#quick-start)
